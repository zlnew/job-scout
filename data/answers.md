## Cover letters

Generated by `npm run cover` (see README), then reviewed by Maul. Never submitted unreviewed.
The script refuses to write a letter without a `--why` research line, quotes only bullets from
`career.json`, and reports JD-only technology as a gap instead of claiming it. Rules for the draft:

- 120–180 words, three paragraphs: what the role needs → the matching `DERIVED` evidence → why
  this company specifically (one researched detail: product, market, or engineering blog).
- Only facts already in `career.json`. No invented metrics, no fabricated enthusiasm.
- Mirror the JD's own vocabulary for the stack it names. Never claim a technology not on the resume.
- If the JD names a gap (K8s, Kafka, gRPC), state the adjacent thing honestly (HorizonX deploys,
  LedgerX ledger design) instead of dodging it.
- Save drafts to `cover-letters/<company>-<role>.md` and log the application row.

## Scoring rubric (every posting)

Title filter first: not Backend/Platform/Product/Full-Stack Engineer → **disqualify.**
Deal-breaker check: relocation, non-remote foreign employer, contract-only without benefits,
or an unconfirmed vertical below → **disqualify.**

Then score from 0:

| Signal | Δ |
|---|---|
| Track (backend / platform / product / full-stack) | +3 / +2 / +2 / +1 |
| Requirements ask 3–5 yrs | +1 (5+ but otherwise strong: 0, flag it) |
| Fintech / payments / platform domain | +2 |
| Remote or Jabodetabek hybrid, stated in the JD | +1 |
| Comp at or above 14M | +1 |
| Flexible / open culture evidence | +1 |
| `DERIVED` facts cover ≥3 of the JD's hard requirements | +2, else 0 |
| Micromanagement or politics signals | −2 |
| Employer is an IT vendor / outsourcing / staffing agency | −1 and `NEEDS_REVIEW`: not preferred, but considered on details (client, contract type, whether it's permanent employment with the vendor). Never a hard reject. |
| Missing an adjacent technology (K8s, Kafka, gRPC, cloud cert, a second language) | 0 — **potential counts**, score on experience and skills shown, never auto-reject for a list gap |
| Missing the role's core language/paradigm (e.g. Java-only shop with no JVM work) | −1, flag it |

≥7 → tailor and apply now. 4–6 → shortlist, apply if the week is quiet. ≤3 → skip.
